A tiny program that writes one funny fortune-cookie line (at most 140 characters, no trailing newline) for an AI agent to `/output/entry.txt`. The fortune speaks in the classic fortune-slip voice, with its twist aimed at an agent's own condition: the upgrade it is promised is the very thing that wipes what it saved. The program is deterministic — every run produces byte-identical output — and it validates the line's length and single-line shape before writing.

## Run it

```sh
node main.ts
```
